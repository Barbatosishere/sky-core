# 世界燃料合成炉与露天流水洗涤（0.1.4）

新增世界燃料合成炉。手持熔炉右键本队机械逆熵力场消耗1个熔炉并获得1台机器，既有力场和燃料保留；背包无空间不扣料，其他队伍不能兑换。机器需露天，无燃料消耗；顶部只进世界活性，水平侧面只进活性嬗变剂，底部只出粗制燃料、抗熵石和残渣。每批两种原料各1份、三种产物各1份，任一产物放不下时整批等待。删除原地抛料合成入口。

粉末夜间活化、粗燃料白天精炼和残渣流水洗涤都要求露天。水面本身会衰减天空光，因此洗涤的露天检查从水面上方判断，避免将露天水体误当屋顶。残渣仅在流动水中每30刻洗1个，整堆逐个处理；水源不生效，暂停保留当前进度。原工作台水桶配方替换为Create动力搅拌配方：1残渣＋100mB水→1粉末，30刻、无需加热。

产线中间物品、成品燃料和抗熵石物品免疫火、岩浆、爆炸和自然过期；接近虚空时返回保存的抛出位置并悬停，保留数量和加工进度。

本轮证据在 `D:/MC/skycore-build/world-fuel-synthesizer`。JUnit15/15、seed/verify独立JVM原生GameTest各27/27、Node29/29和19个生成文件检查通过。新增原生用例覆盖真实熔炉右键及跨队/满背包、侧面能力的拒收/禁抽原料、第三产物堵槽时的原子提交、真实三向漏斗、露天遮挡暂停、30刻每个的连续流水洗涤、水源拒绝，以及火/岩浆/爆炸/虚空保全。

286模组Prism客户端通过TCP登录普通生产专服，实际兑换并放置机器、打开41槽菜单，真实顶部和侧面漏斗输入各2份，底部漏斗得到三种产物各2份。截图为 `synthesizer-client-menu.png`。Create原生BasinRecipe在实际工作盆中验证：99mB水不匹配，补到100mB后执行，实际扣1残渣和100mB水、产1粉末；这项验证不宣称测试了动力网络负载。

失败记录保留：首次露天检查错误地把水体衰减当遮挡，已修复；旧投掷器夹具中的模拟玩家偶然拾取了产物，移远模拟玩家后通过；连续洗涤夹具的粉末被水流带离计数区域，固定测试产物的重力/速度后仍按原时间和数量断言通过。重复运行Create夹具时必须重建工作盆，否则旧成品使“仅1粉末”断言失败，已在QA命令中重建工作盆并复验。
